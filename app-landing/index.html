FAQ

Preguntas frecuentes

¿Necesito una cuenta verificada de WhatsApp Business?
Sí. Atiende utiliza la WhatsApp Business Cloud API de Meta. Necesitás tener un número de WhatsApp Business con API habilitada. Te guiamos en el proceso de setup durante el onboarding.
¿Puedo usar Atiende con mi número actual de WhatsApp?
Podés migrar tu número actual a la API de WhatsApp Business, pero una vez migrado no podrá usarse en la app móvil convencional. Recomendamos tener un número específico para Atiende.
¿Cómo importo mi catálogo de productos?
Desde el panel de administración podés importar tus productos mediante un archivo Excel (.xls/.xlsx). También podés cargarlos manualmente o vía API. El formato está documentado en nuestra guía de inicio.
¿Atiende funciona con múltiples empresas?
Sí. Atiende está construido como plataforma multi-tenant. Cada empresa tiene su propia base de datos, bot, número de WhatsApp y panel de gestión completamente aislados entre sí.
¿Qué pasa si el cliente no responde a los botones interactivos?
El bot detecta respuestas de texto libre y las procesa igualmente. Si el cliente escribe "1" en lugar de tocar el botón "Hacer un pedido", el flujo continúa normalmente.
¿Tiene integración con MercadoPago?
Sí. Atiende genera un link de pago de MercadoPago automáticamente al confirmar el pedido y lo envía al cliente por WhatsApp.
